# 示例图片目录

本目录用于存放提示词生成的示例图片。

## 📋 命名规范

示例图片命名格式：
```
[模型名]-[类别]-[编号].png
```

**示例**:
- `gpt-image-2-portrait-01.png`
- `midjourney-landscape-01.png`
- `stable-diffusion-anime-01.png`

## 📁 文件大小

为了保持仓库轻量：
- 单个图片不超过 2MB
- 使用 PNG 或 JPG 格式
- 推荐分辨率: 1024x1024 或 1024x768

## 🎨 图片要求

示例图片应该：
- ✅ 质量良好，清晰可见
- ✅ 代表性强，展示提示词效果
- ✅ 无水印、无版权问题
- ✅ 内容健康，符合社区规范

## 📝 贡献示例图片

提交示例图片时：
1. 确保图片符合上述要求
2. 在对应的提示词中引用图片
3. 在PR中说明图片来源

## 🔗 引用方式

在提示词文件中这样引用：

```markdown
**示例图片**:
![示例](../../examples/gpt-image-2-portrait-01.png)
```

---

**注意**: 如果示例图片过大，可以考虑：
- 使用图床服务 (如 Imgur, GitHub Issues)
- 放在 Release 中
- 提供外部链接
