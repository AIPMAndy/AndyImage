## 实用技巧

### Flux 特点

1. **速度快** - 生成时间短，适合快速迭代
2. **稳定性好** - 结果可预测，质量稳定
3. **易于使用** - 简单的提示词即可获得好结果
4. **成本低** - 适合大量生成和测试

### 提示词建议

**简洁明了**:
```
modern logo design, blue gradient, minimalist
```

而不是过于复杂的描述。

**关键词优先**:
- 把最重要的描述放在前面
- 使用清晰的风格词
- 避免冗余描述

### 常用关键词

**设计风格**:
- `minimalist`, `modern`, `clean`
- `professional`, `elegant`, `simple`

**色彩描述**:
- `gradient`, `pastel`, `vibrant`
- `monochrome`, `colorful`

**用途说明**:
- `suitable for [具体用途]`
- `perfect for [应用场景]`

### 1. 快速探索

生成多个变体快速对比：
1. 使用简洁提示词
2. 批量生成4-8个
3. 选择最佳方向

选定方向后细化：
1. 添加更多细节描述
2. 调整色彩和风格
3. 优化构图和布局

### 3. 最终输出

确定最终版本：
1. 使用完整的提示词
2. 生成高质量版本
