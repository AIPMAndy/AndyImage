## 使用技巧

### Ideogram 特点

1. **文字精准** - 拼写准确率极高
2. **排版优秀** - 自动优化文字布局
3. **Logo专长** - 特别适合Logo和标识设计
4. **多语言支持** - 支持多种语言文字

### 提示词写作要点

**明确文字内容**:
```
text: "YOUR TEXT HERE"
```
用引号明确标注文字内容

**指定位置**:
```
text at top: "TITLE"
text at bottom: "SUBTITLE"
text in center: "MAIN MESSAGE"
```

**描述风格**:
```
bold typography, elegant serif font, modern sans-serif
```

### 常用描述词

**Logo设计**:
- `logo design`, `brand identity`, `minimalist logo`
- `circular badge`, `letter mark`, `icon design`

**文字风格**:
- `bold typography`, `elegant font`, `modern lettering`
- `hand-drawn text`, `serif/sans-serif`, `script font`

**排版布局**:
- `centered composition`, `balanced layout`
- `text at top/bottom/center`

## 💡 最佳实践

### 1. 文字内容

✅ **推荐**:
- 使用简短有力的文字
- 避免过长的句子
- 大写字母效果通常更好

❌ **避免**:
- 超过3-4个单词的长句
- 复杂的特殊字符
- 不常见的字体样式

### 2. Logo设计

✅ **推荐**:
- 明确品牌名称
- 简洁的图形元素
- 清晰的配色方案

❌ **避免**:
- 过于复杂的图形
- 太多的文字内容
- 不协调的色彩

### 3. 海报设计

✅ **推荐**:
- 主标题醒目突出
- 清晰的视觉层次
- 适当的留白空间

❌ **避免**:
- 文字过多拥挤
- 色彩过于花哨
- 缺乏视觉焦点
