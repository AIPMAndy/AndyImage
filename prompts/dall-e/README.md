## 使用技巧

### DALL-E 3 特点

1. **自然语言理解强** - 可以用完整句子描述
2. **安全性高** - 内容审核严格，适合商业使用
3. **概念理解好** - 能理解复杂的抽象概念
4. **无需特殊语法** - 像说话一样描述即可

### 提示词写作建议

**✅ 推荐做法**:
- 用完整句子描述场景
- 清楚说明用途和风格
- 描述具体细节和氛围
- 说明需要留白的区域

**❌ 避免做法**:
- 过于简短的关键词堆砌
- 要求生成特定品牌logo
- 涉及版权内容
- 不适当的内容

### 提示词结构

```
[场景描述] + [视觉风格] + [色彩和氛围] + [用途说明]
```

**示例**:
```
A modern office space with people collaborating,  # 场景
professional photography style,                   # 风格
bright natural lighting and clean aesthetic,      # 氛围
suitable for corporate website banner.            # 用途
```

### 常用描述词

**商业风格**:
- `professional`, `corporate`, `clean`, `modern`
- `minimalist`, `premium`, `high-end`

**创意风格**:
- `artistic`, `creative`, `unique`, `innovative`
- `playful`, `whimsical`, `imaginative`

**摄影风格**:
- `photography style`, `natural lighting`
- `studio shot`, `commercial photography`

**插画风格**:
- `illustration style`, `hand-drawn`
- `vector art`, `minimalist design`

## 💡 提示词优化技巧

### 1. 明确使用场景

在提示词中说明图片用途：
```
suitable for [LinkedIn banner / Instagram post / product packaging]
```

### 2. 描述留白区域

说明哪里需要添加文字：
```
with space at top for headline text
empty area at bottom for call-to-action
```

### 3. 指定视觉风格

明确风格参考：
```
in the style of [modern corporate photography / minimalist design]
```

### 4. 控制色彩情绪

描述色彩和氛围：
```
warm inviting colors, professional yet approachable
cool corporate blues and whites, trustworthy atmosphere
```

## 🚫 内容限制

DALL-E 3 有严格的内容审核，以下内容会被拒绝：

- ❌ 知名人物肖像
- ❌ 受版权保护的角色/logo
- ❌ 暴力、成人内容
- ❌ 政治敏感内容
- ❌ 仇恨、歧视内容

**替代方案**: 用通用描述代替具体名称
- ✅ "a famous scientist" 而不是 "Albert Einstein"
- ✅ "superhero in red and blue" 而不是 "Spider-Man"
