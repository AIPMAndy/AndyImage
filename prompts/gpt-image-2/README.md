## 💡 使用技巧

### GPT Image 2 特有优势

1. **文字渲染** - 可以直接在图中生成文字，准确率高
2. **自然语言理解** - 用日常语言描述即可，无需特殊语法
3. **安全性** - 内容审核严格，适合商业使用
4. **一致性** - 同一提示词多次生成结果较为稳定

### 提示词优化建议

1. **明确文字内容** - 用引号包裹想要的文字: `text: "YOUR TEXT"`
2. **指定留白区域** - 说明哪里需要放置文字: `copy space at top`
3. **描述排版** - 说明文字位置和大小: `large text at center`
4. **风格一致** - 保持整体设计风格描述一致

### 常见问题

**Q: 文字有时候会拼写错误怎么办？**
A: 使用引号明确包裹文字，简化单词，避免过长的句子

**Q: 如何让图片更商业化？**
A: 添加关键词: `professional, commercial, high-end, corporate`

**Q: 生成的图片分辨率够用吗？**
A: 选择HD质量可获得1024x1024或更高分辨率，满足大部分商业需求
