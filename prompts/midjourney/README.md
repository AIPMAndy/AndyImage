## 参数使用指南

### 常用参数说明

| 参数 | 说明 | 示例 |
|------|------|------|
| `--ar` | 纵横比 | `--ar 16:9`, `--ar 1:1`, `--ar 2:3` |
| `--v` | 版本号 | `--v 6` (最新), `--v 5.2` |
| `--s` | 风格化程度 | `--s 250` (0-1000，默认100) |
| `--c` | 混沌程度 | `--c 50` (0-100，增加变化) |
| `--q` | 质量 | `--q 2` (0.25, 0.5, 1, 2) |
| `--style` | 风格 | `--style raw` (原始), `--style cute` |
| `--niji` | 动漫模式 | `--niji 6` |
| `--tile` | 可平铺 | 用于创建无缝纹理 |
| `--no` | 排除元素 | `--no people, cars` |

### 推荐参数组合

**写实摄影**:
```
--ar 16:9 --style raw --v 6
```

**艺术插画**:
```
--ar 4:5 --s 250 --v 6
```

**动漫风格**:
```
--ar 16:9 --niji 6
```

**产品设计**:
```
--ar 1:1 --style raw --q 2 --v 6
```

**概念艺术**:
```
--ar 16:9 --s 180 --v 6
```

## 💡 高级技巧

### 提示词结构建议

```
[主体] + [细节描述] + [环境/背景] + [光线] + [风格] + [质量词] + [参数]
```

示例:
```
Fantasy dragon + scales texture, golden eyes + mountain cliff background 
+ dramatic sunset lighting + concept art style + highly detailed 
+ --ar 16:9 --v 6
```

### 权重控制

使用 `::` 来控制权重（仅V5+）:
```
red::2 blue::1 means红色权重是蓝色的2倍
```

### 多提示词混合

使用 `::` 分隔不同概念:
```
portrait::1.5 landscape::1 abstract::0.5
```
